==================================================
PHASE 4 — TRANSACTION NORMALIZATION
==================================================

Raw Solana RPC responses are too complicated for the UI and AI.

Create a normalized transaction model.

For example:

{
  signature: string,
  timestamp: number | null,
  status: "success" | "failed",
  type: "transfer" | "swap" | "token_transfer" | "unknown",
  protocol: string | null,
  feeSol: number,
  solChange: number,
  tokenChanges: [],
  source: string | null,
  destination: string | null
}

Create a transaction parser that converts raw Solana transactions into this normalized format.

Initially support:

1. SOL transfers
2. SPL token transfers
3. SOL balance changes
4. Transaction fees
5. Basic protocol/program identification
6. Unknown transactions

Do NOT pretend an unknown transaction is a swap.

If the parser cannot confidently determine what happened, mark it as:

"type": "unknown"

==================================================

Structured wallet summary

AI
